# GastroVoyage

Baku-first mobile product for discovering world dishes available in Baku, tracking personal tasting progress, and attaching proof photos.

## Monorepo Structure

- `mobile`: Flutter application.
- `backend`: FastAPI backend with PostgreSQL/PostGIS-ready schema.
- `docs`: product, legal, and architecture decisions.
- `docs/API_CONTRACT.md`: frozen backend-mobile payload contract.

## Product Scope (MVP)

- Interactive map focused on Baku dish discovery.
- Dish details with restaurant recommendations in Baku.
- User tasting history with photo proof.
- Challenge progress across cuisines/countries.
- Admin APIs for content management.

## Legal Boundary

This project uses original data and content only. No automated scraping or direct copying of third-party protected databases or proprietary text/media is allowed.
